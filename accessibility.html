มาตรฐานที่ปฏิบัติตาม

เว็บไซต์นี้ออกแบบให้สอดคล้องกับ Web Content Accessibility Guidelines (WCAG) 2.1 ระดับ AA ซึ่งกำหนดโดย World Wide Web Consortium (W3C)

การทดสอบล่าสุดดำเนินการด้วย axe-core 4.9.1 ผล: 0 violations / 44 passes

คุณสมบัติด้านการเข้าถึงที่มีให้

  • Skip link — ลิงก์ "ข้ามไปยังเนื้อหาหลัก" ปรากฏเมื่อกด Tab เพื่อให้ผู้ใช้ keyboard ข้ามเมนูได้
  • Landmark regions — ใช้ <nav>, <main>, <footer> สำหรับ screen reader
  • Heading hierarchy — โครงสร้าง h1 → h2 → h3 เป็นลำดับ ไม่ข้ามระดับ
  • Color contrast — ทุก text element ผ่านอัตราส่วน 4.5:1 (ข้อความปกติ) หรือ 3:1 (ข้อความขนาดใหญ่)
  • Keyboard navigation — ทุก element ที่ interactive สามารถ focus ได้ด้วย Tab พร้อม focus ring ที่เห็นชัด
  • Form labels — ทุก field ในฟอร์มติดต่อมี label เชื่อมกันด้วย for/id
  • ARIA attributes — ปุ่มเมนู มี aria-expanded, ปุ่มเลือกภาษามี aria-pressed
  • Language attribute — html[lang] อัปเดตอัตโนมัติตามภาษาที่เลือก (ไทย/อังกฤษ)
  • Reduced motion — ปิด animation ทั้งหมดเมื่อผู้ใช้เปิด "Reduce Motion" ในระบบปฏิบัติการ

ข้อจำกัดที่ทราบ

Gradient text — ข้อความหัวเรื่อง "built for Thai businesses" ใช้การไล่สีแบบ CSS gradient ซึ่งเครื่องมืออัตโนมัติไม่สามารถตรวจสอบ contrast ได้ครบถ้วน อย่างไรก็ตาม ได้รับการตรวจสอบด้วยตนเองแล้ว และส่วนที่เข้มที่สุดของ gradient ผ่านอัตราส่วน 3:1 สำหรับข้อความขนาดใหญ่ (WCAG 1.4.3)

Commitment to Accessibility

Digitaltransform Co., Ltd. is committed to ensuring digitaltrans.biz is accessible to everyone, including people with visual, auditory, motor, or cognitive disabilities.

Conformance Status

This website is designed to conform to Web Content Accessibility Guidelines (WCAG) 2.1 Level AA, published by the World Wide Web Consortium (W3C).

Latest automated test using axe-core 4.9.1: 0 violations / 44 passes. Continuous integration runs on every code push via GitHub Actions.

Accessibility Features

  • Skip link — "Skip to main content" appears on Tab focus, allowing keyboard users to bypass navigation
  • Landmark regions — Proper <nav>, <main>, <footer> elements for screen reader navigation
  • Heading hierarchy — Sequential h1 → h2 → h3 structure with no skipped levels
  • Color contrast — All text passes 4.5:1 (normal text) or 3:1 (large text) thresholds
  • Keyboard navigation — All interactive elements are reachable by Tab with a visible focus ring
  • Form labels — Every contact form field has a programmatically associated <label>
  • ARIA attributes — Menu button uses aria-expanded; language toggles use aria-pressed
  • Language attribute — html[lang] updates automatically when Thai/English is toggled
  • Reduced motion — All animations are suppressed when "Reduce Motion" is enabled in the OS

Known Limitations

Gradient text — The headline "built for Thai businesses" uses a CSS gradient applied via background-clip: text. Automated tools cannot fully verify gradient contrast. Manual inspection confirms the dominant (darkest) portion of the gradient meets the 3:1 ratio for large text per WCAG 1.4.3.
